# The Iron Journal — From Zero to Built

A buildless HTML/CSS/JavaScript educational site with 13 chapters, locally bundled GSAP/ScrollTrigger and Three.js, an original hero illustration, simplified interactive anatomy, exercise guidance, calorie and macro estimates, Indian meal menus, workout routines, a local progress journal, browser narration and original synthesized ambience.

## Run
Serve `dist/` with any static HTTP server. For example `python3 -m http.server 8080 --directory dist`. ES modules require HTTP; do not double-click index.html. The app uses hash routes and includes `404.html` for unknown server paths.

## Validate
`npm test` checks reference calculations, input rejection, meal arithmetic, content coverage and PDFs. `npm run build` also validates JavaScript syntax and static hosting configuration.

## Content and documents
`dist/data.js` contains original lessons, exercise instructions, approximate generic food composition values and source links. `scripts/content.json` is the PDF generation snapshot. Regenerate it after content edits with a Node import, then run `scripts/make_docs.py` using Python with ReportLab. Thirteen PDFs are prebuilt in `dist/docs/`.

## Data and limitations
Journal entries are localStorage-only. They are not encrypted, backed up or synchronized. Export controls produce a JSON backup; the website does not currently import backups. Photos are resized locally, limited to 12. No account server or external database is used. Private hosting controls who can load the site, not who can access an already-open browser profile.

Nutrition values and INR prices are illustrative estimates, not live food database queries or market prices. Calculators are adult education tools, not clinical advice. Transformations are fictional illustrations, never expected gains. Anatomy is a simplified selectable 3D map, not a medical-grade mesh. Exercise demonstrations are stylized SVG movement cues accompanied by written technique guidance. Narration uses device speech synthesis; voices and support vary. Ambience and short effects are generated by Web Audio, not licensed recordings. The four-scene introduction is skippable. Reduced-motion preferences disable decorative CSS/GSAP motion.

Fonts load from Google Fonts with local system fallbacks. JavaScript libraries are bundled locally; their license headers are retained. Scene cleanup disposes WebGL resources on navigation. Images use WebP. All application state changes are on-device.
